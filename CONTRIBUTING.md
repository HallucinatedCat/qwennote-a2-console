# Contributing

This is a small, unofficial project with a narrow scope. To keep it manageable:

1. **Issues come first.** Use the bug report or feature request form; blank issues are disabled. A form that is incomplete, or out of scope, is closed without reply.
2. **Pull requests close an accepted issue.** One change per pull request, using the template. A check enforces the template; pull requests that keep failing it are closed.
3. **Out of scope, always:** functions listed under *Not supported* in [docs/capabilities.md](docs/capabilities.md); firmware, reset or other people's devices; anything that bypasses a vendor limit, quota, payment or access check; credential extraction; code or assets copied from the vendor's apps.
4. **Never post private data** in issues, pull requests or test fixtures: tokens, session files, account or device identifiers, serial numbers, phone numbers, note text, audio or signed links. Use invented values, as the existing tests do.
5. **Questions** about the A2, the QwenNote app or your account belong to [QwenNote](https://docs.qwennote.cn/zh/a2), not here.

Security problems: see [SECURITY.md](SECURITY.md).
