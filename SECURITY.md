# Security

Report vulnerabilities privately: **[open a security advisory](https://github.com/HallucinatedCat/qwennote-a2-console/security/advisories/new)**. Do not open a public issue or pull request for a security problem.

In scope: this repository's code, meaning the console backend and web UI, the MCP reader, the demo and the tools. Examples: a way to reach the console from another machine or origin, a CSRF or injection path, credentials leaking into logs, the browser or files with loose permissions.

Out of scope: the vendor's own apps, servers and devices (report those to QwenNote), and setups that expose the console beyond 127.0.0.1 against the documentation.

Include the commit, the steps to reproduce and the impact. Leave out real credentials and personal data. There is no bug bounty.
